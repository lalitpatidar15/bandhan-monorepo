# Project Index

Last updated: 2026-11-22
Project: Bandhan multi-app ecommerce/events/learning/jobs platform
Project type: pnpm + turbo Next.js monorepo with Express API

Binding instructions: `../AGENTS.md` (parent of repo) and `../BANDHAN_UI_MODERNIZATION_CODEX.md`.
Those documents override generic conventions. UI work must be modernization in place, not a redesign.

## Technology

- Languages: TypeScript (frontends), JavaScript CommonJS (API)
- Frameworks: Next.js 16 (App Router), Express 5, Mongoose, Socket.IO, Tailwind 3/4, RTK Query
- Package manager: pnpm; build orchestration: turbo
- Shared packages publish raw TS source via `exports` (`packages/ui`, `packages/types`, `packages/config`); no build step. Keep `import "@bandhan/ui/styles.css"` in every app `app/layout.tsx`.

## Auth / connectivity

- `apps/user` is the only sign-in. Portals receive single-use SSO code (2-minute TTL, `POST /api/auth/sso/exchange`, `SsoGrant` stores hash only). Admin is separate.
- API base URL is `NEXT_PUBLIC_API_URL` only. `NEXT_PUBLIC_BACKEND_URL` is unused dead config.
- API requires `MONGO_URI` and `JWT_SECRET`. `apps/api/.env` contains live credentials — gitignored, never read out or commit.
